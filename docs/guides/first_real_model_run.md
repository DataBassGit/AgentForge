# First Real Model Run

This guide continues from the [Quickstart](quickstart.md).

The quickstart proved that AgentForge can load `.agentforge/`, render `hello_agent`, and return a debug response without credentials.

This step turns debug mode off so the same direct Agent calls a real model provider.

## Start From The Quickstart Project

Use the same project that already has:

- `.agentforge/`
- `.agentforge/prompts/hello_agent.yaml`
- `run_hello_agent.py`

The script stays the same:

```python
from agentforge.agent import Agent

result = Agent("hello_agent").run(user_input="AgentForge")
print(result)
```

## Turn Debug Mode Off

From your project root, set `debug.mode` back to `false`:

```shell
python -c "from pathlib import Path; p = Path('.agentforge/settings/system.yaml'); text = p.read_text(); p.write_text(text.replace('mode: true', 'mode: false', 1))"
```

You can also edit `.agentforge/settings/system.yaml` directly:

```yaml
debug:
  mode: false
```

When debug mode is off, AgentForge calls the provider selected in `.agentforge/settings/models.yaml`.

## Default Provider: Gemini

The current scaffold starts with Gemini as the default real model:

```yaml
default_model:
  api: gemini_api
  model: gemini_flash
```

Gemini requires `GOOGLE_API_KEY`.

On macOS or Linux:

```shell
export GOOGLE_API_KEY="your-google-api-key"
```

On Windows PowerShell:

```shell
$env:GOOGLE_API_KEY="your-google-api-key"
```

Run the same script:

```shell
python run_hello_agent.py
```

The output is generated by the model, so the wording will vary.

It should be a real greeting to AgentForge.

It should not be the exact debug response:

```text
Hello from AgentForge debug mode.
```

If `GOOGLE_API_KEY` is missing, the Gemini call cannot run.

## Short Provider Alternatives

Use one of these alternatives only after the debug quickstart works.

For detailed model configuration, see [Model Settings](../settings/models.md).

### OpenAI

Set `OPENAI_API_KEY`, then edit `.agentforge/settings/models.yaml`:

```yaml
default_model:
  api: openai_api
  model: gpt4o_model
```

The packaged `gpt4o_model` entry points at OpenAI's `gpt-4o` model.

### Codex OAuth

Codex models use OAuth instead of `OPENAI_API_KEY`.

Verify or initialize OAuth first:

```shell
python -m agentforge.init_codex_oauth --check
```

If the check says credentials are missing, run:

```shell
python -m agentforge.init_codex_oauth
```

Then edit `.agentforge/settings/models.yaml`:

```yaml
default_model:
  api: openai_api
  model: codex_gpt55
```

The packaged `codex_gpt55` entry points at the `gpt-5.5` Codex model.

### Ollama

Ollama does not need a cloud API key, but the Ollama service must be running and the model must be installed.

Check your local models:

```shell
ollama list
```

Edit `.agentforge/settings/models.yaml`:

```yaml
default_model:
  api: ollama_api
  model: local_ollama

model_library:
  ollama_api:
    Ollama:
      models:
        local_ollama:
          identifier: qwen3.5:9b
```

Replace `qwen3.5:9b` with a model name from your own `ollama list`.

Keep the existing Ollama `params` block in `models.yaml`; only the model key and identifier need to match your local model.

### LM Studio

LM Studio does not need a cloud API key, but its local server must be running.

Start the LM Studio server, load a chat model, then edit `.agentforge/settings/models.yaml`:

```yaml
default_model:
  api: lm_studio_api
  model: llama3_8b
```

If your loaded model uses a different identifier, update the matching `model_library.lm_studio_api.LMStudio.models` entry so its `identifier` matches the model served by LM Studio.

## Troubleshooting The First Real Call

- If you see the debug response, `debug.mode` is still `true`.
- If Gemini fails before sending a request, check `GOOGLE_API_KEY`.
- If OpenAI fails before sending a request, check `OPENAI_API_KEY`.
- If Codex fails before sending a request, run `python -m agentforge.init_codex_oauth --check`.
- If Ollama or LM Studio fails, make sure the local service is running and the configured model identifier matches an available model.
